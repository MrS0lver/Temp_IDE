# UK LightWeight - Advanced C/C++ IDE

UK LightWeight is a lightweight and functional Integrated Development Environment (IDE) specifically built for C/C++ programming. It offers a clean and minimalist interface for code editing and compiling with added convenience for both beginners and advanced programmers. Unlike other IDEs, UK LightWeight provides a straightforward, easy-to-use experience with integrated social media links and a unique code-execution mechanism optimized for C/C++ projects.

## Features
- **File Operations**: Open, save, and create new C/C++ files quickly with an intuitive menu.
- **Line Numbers**: Real-time line numbering for easy navigation and code reference.
- **Integrated Compiler**: Compiles code with `g++`, handling both code execution and user input as required by C++ programs.
- **Output Area**: Displays standard output and error messages, enhancing debugging and development workflow.
- **User Input Prompt**: Allows input data entry for programs that use `cin`, making it ideal for interactive C++ applications.
- **Run and Clear Buttons**: Execute code with the press of a button, and clear output with ease.
- **Social Media Links**: Direct access to GitHub, Twitter, and Instagram to stay connected with the development community.

## Installation
This project is developed using Python’s Tkinter library and requires `g++` for compilation. Ensure the following dependencies are available on your system:

- **Python 3.x**
- **Tkinter** (included with Python standard library)
- **g++** (for compiling C++ code)

To install any missing dependencies, run:
```bash
# For Debian/Ubuntu
sudo apt-get install python3-tk g++
